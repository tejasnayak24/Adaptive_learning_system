# Browser acceptance

## What has been tested (2026-11-13, Phase 7)

**Setup:**
- Real Google Chrome (headless), driven by Playwright.
- Running against the Vite dev server and the production build.
- Backend on an **isolated copy** of the database (`aegis_phase7`), so the
  live database was untouched.
- The **real camera agent** (HTTP server, pairing, heartbeats, detectors and
  voice-alert logic) with a **synthetic camera**: scripted face landmarks
  for normal, no face, yawning, looking away, eyes closed and camera
  failure. No webcam was used.

Screenshots were taken at 1366×768 and 375×812 and inspected for broken
layouts, blank pages, wrong charts and overflow.

| Area | Automated checks | Result |
|---|---|---|

Totals: journey 38/38, extra checks 9/9, production smoke 7/7.

**Bugs found by these runs and fixed in Phase 7:**
- **False "Webcam unavailable" flash.** About 1.5 s after consent on every
  lesson start. The backend still held the agent's "camera starting"
  heartbeat.
- **Lesson from another grade.** It asked for camera verification before
  showing the refusal.
- **Missing registration message.** The "Registration successful" message
  was not shown on the sign-in page.
- **Results-page wording.** "1 hints" was ungrammatical, and the panel
  claimed "PostgreSQL saved".
